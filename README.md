## 怎么算出一台云服务器的精确价格

关键是把配置填全。操作系统、系统盘和数据盘、公网带宽、购买数量都会影响最终价格，缺了任何一项，算出来的都只是参考价。以云服务器为例，完整流程是这样的：

1. 选地域和时长，两项都支持多选。想对比北京、杭州、上海三地，或者同时看“1个月”和“3个月”的报价，一次勾选就行，不用反复查。
2. 输入规格，比如4核8G，右侧会出现符合条件的候选服务器列表，按价格从低到高排列。
3. 点“选择此规格”，查看该规格可选的可用区列表。
4. 补全详细配置：操作系统、系统盘/数据盘大小、公网带宽、数量。官方文档里的示例是一台40G系统盘、加一块100G数据盘、1M公网带宽的机器。
5. 点“询价并加入”，右侧显示价格。前面如果勾了两个时长，这里会分别给出两个时长对应的价格，这就是这台机器的精确报价。

> 留意库存提示：如果某个规格在你选的地域没货，点“选择此规格”后可用区列表会是空的，右侧出现红色提示“该规格未查询在（XX地域）正在售卖的可用区”。价格再低，没库存也下不了单，所以看到便宜规格先确认可用区还有货。

数据库也是同样的路子。官方示例里的RDS询价：选MySQL 8.0，规格rds.mysql.s3.large（4核8G），100G ESSD PL3云盘，买2台，付费类型选预付费的1个月和3个月，点“询价并加入清单”后，报价直接出现在右侧清单里。

## 多地域、多规格比价：同样的配置能差出多少

在同一张询价里勾选多个地域，结果会按价格从低到高排列，最低价一眼可见，这是CADT计算器最实用的功能。

官方帮助文档里给过一组例子：对比北京、杭州、乌兰察布三地的ecs.c6a.xlarge，乌兰察布最便宜，杭州和北京同价。但点“选择此规格”之后发现，乌兰察布已经没有这个规格的库存，北京和杭州还有。这个例子很典型，低价规格要配合库存提示一起看，别等下单时才发现白高兴一场。

另一个方向是同地域比不同型号。同样在北京、同样是4核8G，ecs.c6a.xlarge、ecs.g6a.xlarge、ecs.c6.xlarge这些规格的价格各不相同，计算器会把它们按价格从低到高列出来。选机器时别只盯着型号名，同配置下多看一眼报价，差价有时不小。

很多教程只讲到“选规格看价格”就结束了，其实跨地域和跨型号这两组对比才是省钱的关键：不限定地域时多勾几个，同配置时把候选型号都拉出来排个序，两分钟的事。

## 用计算器询价前，先知道这几点

计算器本身不难用，容易出问题的主要是价格时效和配置完整度，集中列一下：

- 价格是实时查的，会变。清单专门配了“重新询价”按钮，说明报价有时效性，隔了几天再下单，先把清单刷新一遍。
- 配置填得越全，报价越准。操作系统、磁盘、带宽、数量、时长一样都不能少，只选规格的价格只能用于粗筛。
- 多选功能别浪费。地域和时长都支持多选，一次询价能拿到多组结果，比逐个查询省太多时间。
- 产品覆盖有边界。CADT计算器目前支持10种云产品，主站计算器覆盖面更广，但不在列表里的长尾产品还是得去对应产品页看定价；业务在海外的话，阿里云国际站另有单独的价格计算器，支持的产品列表略有差异。
- 分清两种计费方式。云服务器这类产品同时有包年包月和按量付费：前者按选定时长付费，适合长期稳定跑的业务；后者按实际用量计费，随开随停，适合短期项目和测试环境。

## 关于阿里云价格计算器的常见问题

### 计算器算出的价格就是下单价格吗？

填全配置后得到的就是精确报价，但价格本身是实时查询的结果，会随官方调整变动。下单前点一次“重新询价”，确认数字没变再付款。

### 能同时对比多个地域的价格吗？

能。地域和时长都支持多选，官方示例里就同时选了北京、杭州、上海三个地域，加上“1个月”“3个月”两种时长，右侧列表按价格从低到高排列，最低价直接排在最前面。

### 报价单怎么发给别人？

两种方式：点“分享当前清单”生成链接，对方打开后可把清单按自己的实时价格保存进账号；或者导出Excel报价单，包含产品类型、规格配置、地域、时长、数量和价格，适合走正式流程。

### 要算的产品不在计算器里怎么办？

CADT计算器目前支持10种云产品，主站计算器覆盖面更广，点“更多”可以切换。列表外的产品，去对应产品页查看定价即可。
